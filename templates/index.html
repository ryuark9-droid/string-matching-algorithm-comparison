Meet the algorithms

A QUICK FIELD GUIDE
01O(n · m)

Naive search

Slides the pattern one position at a time, checking every character. Simple to understand, but repeats work when a match fails.

BEST FOR Small inputs · Baseline comparison
02O(n + m)

Knuth–Morris–Pratt

Builds a prefix table so it can skip comparisons it already knows. Never moves backward through the text.

BEST FOR Long text · Predictable performance
03AVG O(n + m)

Rabin–Karp

Compares rolling hashes to rule out unlikely matches quickly, then checks characters when hashes align.

BEST FOR Multiple patterns · Fast average case
